# 디버그 주소 모음

[← 문서 안내](README.md)

테스트할 구역이나 기능 앞에서 바로 시작하는 주소입니다. 정상 플레이에는 영향이 없습니다.

## 쓰는 법

1. 주소 끝에 `?debug=…`를 붙여 연다.
2. 타이틀에서 **새로운 여정**을 시작한다. 바로가기는 새 게임을 만들 때만 적용되고, 이어하기에는 적용되지 않는다.
3. 옵션은 `&`로 잇는다. 예: `?debug=village&lv=4&plv=60`

| 어디서 | 주소 앞부분 |
|---|---|
| 배포 사이트 | `https://ashfall-chronicles.vercel.app/play/` |
| 로컬 | `game/` 폴더에서 `python3 -m http.server 8000` → `http://127.0.0.1:8000/` |
| zip 빌드 | `index.html` 을 연 뒤 주소창 끝에 붙인다 |

> 배포 사이트에는 `bash tools/build-site.sh`로 빌드해 배포한 뒤에 반영된다. 새로 생긴 `?debug=factory`도 마찬가지다.

## 예시 공장 (`?debug=factory`) 배치

캠프 오른쪽, 한 줄로 늘어선 순서입니다. 전주는 10칸마다 서 있어 전체가 전력망 하나입니다.

| 칸 | 내용 |
|---|---|
| −3 | 자재 상자: 석탄·광석·주괴·강철판·수지·전선·원유·대갈못·밀·밀가루·생고기·모래·해초·게 껍데기·소금·빈 배터리 |
| 1~8 | 전력: 화력 발전기 둘(석탄·압축 연료) · 축전지 · 강화 축전지 · 풍차 · 정지 스위치 |
| 11~18 | 제련 줄: 상자(배출) → 벨트 → 자동 용광로 → 벨트 → 고속 벨트 → 상자 |
| 21~26 | 압축 줄: 석탄 상자 → 압축기 → 분류기(압축 연료만 통과) → 상자 |
| 31~38 | 유혈암 위 시추 펌프 → 정제기 → 상자 · 자동 포탑(대갈못) · 전격 함정 |
| 41~45 | 조립 줄: 구리 주괴 상자 → 조립기(수지·전선·금 미리 넣음) → 상자 |
| 51~56 | 광맥 위 기계식 드릴 · 전동 드릴 → 각자 상자 |
| 61~72 | 가압기 · 염수 증류기 · 밀링기 · 화덕 → 각자 상자 |
| 74~81 | 화살 발사기 · 화염 분사구 · 서리 분사구(위를 향함) · 빈 배터리를 충전하는 축전지 |

기계를 **우클릭**하면 기계 화면이 열립니다. 헤드리스 브라우저로 12초 돌려 본 결과는 다음과 같습니다.

- 26종이 모두 섰다.
- 가공 기계는 모두 '가동' 상태였다.
- 바닥에 떨어진 아이템 0, 콘솔 오류 0.

## 알아 둘 것

- `?debug=sea`는 3장 분량을 건너뛴다. 시작 장(15)의 목표를 주어진 아이템이 바로 채워, 15·16·17장이 연달아 완료된다. 보상 경험치 5.2M·8M·14M이 쌓여 레벨 371, 18장에서 시작한다. 세션 3 장 진행을 시험할 때는 `ch=`로 장을 직접 고르고, 이 점을 감안할 것.
- 바로가기의 레벨 올리기는 `xpNext`를 레벨당 ×1.18로 늘린다. 실제 레벨업 공식(`40 × 레벨^1.42`)과 달라서, 경험치 막대 길이가 실제 플레이와 다르다.
- 세계 크기(소형·중형·대형)는 주소로 고를 수 없다. 새 게임 창에서 고른다.
