## 1. 장·세션을 늘릴 때 손대는 자리

**장 색인 표는 거의 전부 `clamp` 나 `Math.min` 으로 끝 칸을 물고 있습니다.**
그래서 표를 안 늘려도 **에러가 안 납니다** — 조용히 이전 장의 것이 나옵니다.
그게 이 목록이 필요한 이유입니다. 실제로 `DIALOGUE` 가 여덟 칸뿐이라 7~14장
여덟 장이 같은 대사를 하고 있었고, 아무도 몰랐습니다.

### 1-1. 반드시

| 자리 | 파일 | 빠뜨리면 |
|---|---|---|
| `SESSIONS` | `data.js` | 새 세션이 세션 2 규칙으로 돈다. **한 줄만 더하면 나머지는 따라옵니다** |
| `CHAPTERS` | `data.js` | 장 자체가 없음 |
| `CHAPTER_HOOK` | `data.js` | 장 끝에 "다음이 궁금해지는 한 줄"이 안 뜸 |
| `STORY_BOSSES` | `data.js` | 그 장의 결착이 보스로 안 잡힘 |
| **`DIALOGUE` — 아홉 사람 전부** | `data.js` | **이전 장 대사를 반복.** 캠프 넷은 0번부터, 여명 다섯은 9번부터 칸이 있습니다. 새 사람이 생기면 그 사람의 첫 장까지 `null` 로 채웁니다 |
| `CH_MOB` · `CH_ORE` · `CH_MAT` | `data.js` | 부탁이 새 세션에서 **세션 2 재료**를 요구 |
| `BOUNTY_POOL` | `data.js` | 게시판이 안 붙음. `s:` 에 세션, `ch: [처음, 끝]` 에 장 범위. **한 장에 최소 세 장(張)이 붙어야 하므로 새 세션에 못해도 여섯 종은 필요** |
| `SIDE_POOL` | `data.js` | 부탁 문장이 옛 장 기준으로 나옴 |
| `ENEMIES` | `data.js` | 새 몹의 `biome` · `drops` · `cw`(세는 말: 기계는 `'기'`) |
| `TILE_DEF` | `data.js` | 새 타일과 `drop` |
| `MAT` · `TILE_MAT` · `MOB_MAT` | `data.js` | 새 재질의 소리·파편. 안 적으면 전부 `stone`/`flesh` |
| `ORE_TIER` | `data.js` | 새 광물 값이 `hard` 로 어림잡힌다. 광맥은 **캐는 쪽이 값을 정하므로** 여기 적는 것이 곧 그 재료의 시세 |
| `BOSS_DIE` | `data.js` | 새 보스가 쓰러질 때 기본 연출로 떨어짐 |
| `SKILL_FX` | `data.js` | 새 스킬이 소리도 흔들림도 시전 고리도 없이 나감 |
| `RUIN_SPEC` | `data.js` | 새 유적 없음. **유적마다 고유 몹 하나**가 이 게임의 약속입니다 |
| `biomeAt()` | `world.js` | 새 바이옴이 안 생김 |
| parallax 키 분기 | `game.js` `drawParallaxArt` | 새 바이옴이 숲 배경을 씀. **지상 바이옴에만 답니다** — 땅속은 벽지에 다 덮여 한 픽셀도 안 보입니다(2-5절) |
| `manifest.json` → `sync-manifest.mjs` | `assets/`, `tools/` | **게임은 `sprites-manifest.js` 를 읽습니다.** json 만 고치면 아무 일도 안 일어남 |
| `?v=` | `game/index.html` | 브라우저가 옛 파일을 계속 씀 |

### 1-2. 잊기 쉬운 것

- **`ashF()`** — 지금은 "세션 2 이상이면 0"입니다. 세션 3 에 고유한 세계 변질
  (잿빛 같은 것)이 있다면 여기에 곡선을 하나 더 답니다.
- **`MECH_CH0` / `MECH_CH1`** (9, 14) — 개조가 번지는 구간. 세션 3 은 개조가
  끝난 뒤이므로 그대로 두면 전부 개조된 채로 나옵니다. 의도인지 확인할 것.
- **일지 탭** — `SESSIONS` 에서 만들어지므로 자동입니다. 다만 탭의 `t`(부제)는
  **스포일러가 아닌 말**로 적습니다(사이트 방침과 같음).
- **사이트에 박힌 수치** — 홈의 "아이템 ○○종 · 몬스터 ○○종". 늘리면 같이 고칩니다.
- **`docs/v1.1-changelog.md`** — 세션 3 이 v1.2 라면 새 changelog 를 뜹니다.

### 1-3. 절대 바꾸지 않는 것

- **`WW=4200 × WH=480`** — 세이브 로더가 `d.world.ww !== WW` 면 로드를 거부합니다.
  **바꾸면 모든 기존 세이브가 죽습니다.** 새 바이옴은 지금 폭 안에서 자리를 냅니다.
- **월드 생성의 난수** — 지형은 시드 `rng`, 연출·전투는 `Math.random()`.
  섞으면 같은 시드가 같은 세계를 안 만듭니다.
- **`game/` 이 유일한 원본** — `site/play/` 는 빌드 산출물이고 `.gitignore` 입니다.

## 2. 이번에 세운 규칙 — 세션 3 에서도 그대로

각 줄은 **실제로 한 번 물린 것**입니다. 추상적인 원칙이 아니라 흉터입니다.

### 2-1. 표로 굴린다. 같은 판단을 두 곳에 적지 않는다

"세션 2인가"가 `chapter >= 9` 로 **아홉 군데**에 손으로 적혀 있었습니다.
세션 3 을 붙이려면 아홉을 다 찾아야 했고, 하나를 빠뜨리면 **에러 없이**
3세션에서 2세션 규칙이 돕니다. 지금은 `SESSIONS` 한 줄입니다.

같은 이유로 이번에 표로 옮긴 것들 — 스킬의 소리·흔들림·멈춤(`SKILL_FX`),
보스가 무너지는 방식(`BOSS_DIE`), 재질(`MAT`), 물건값(`ITEM_VAL`),
의뢰 값(`QUEST_PAY`). **새 내용은 코드가 아니라 이 표들에 줄을 더해서 붙입니다.**

### 2-2. 장 색인 표는 clamp 가 곧 버그다

`Math.min(ch, 길이-1)` 은 표가 짧아도 안 죽습니다. 대신 **조용히 틀립니다.**
표를 늘릴 때는 1절 목록을 위에서 아래로 훑습니다. 새 장을 넣고 나서
"7~14장이 같은 말을 하지 않는가"를 실제로 재 보는 것이 가장 빠릅니다.

### 2-3. 눈으로 보지 말고 잰다

- 프레임 차이를 **제자리에서** 빼면 그림이 통째로 한 칸 미끄러진 것도 26~50%로
  나옵니다. 겹쳐 놓고 **남는 차이**를 재야 관절이 움직였는지 보입니다
  (`tools/animcheck.py`). 이 차이로 멈춘 애니메이션 129칸을 찾았습니다.
- 값·보상·밀도처럼 숫자로 된 것은 **고치기 전과 후를 같은 자로 재서** 적습니다.
  changelog 의 숫자들이 전부 그렇게 나온 것입니다.

### 2-4. 손맛의 규칙

| | |
|---|---|
| **입력을 삼키지 않는다** | 못 쓰는 스킬을 눌러도 소리와 흔들림으로 대답합니다. 조용히 `return` 하면 키가 안 먹은 것과 구별이 안 됩니다 |
| **큰 것은 세계를 멈춘다** | 히트스톱 0.03~0.10초. `dt` 를 0 으로 두면 물리가 한 프레임 건너뛰어 관통이 생기므로 0.12배로 흘립니다 |
| **한 획마다 조금씩 다르다** | 같은 소리를 그대로 반복하면 세 번째부터 "같은 소리"로 들립니다. ±6% 로 음을 흔듭니다 |
| **소리는 갈래로 묶고 파일은 적게** | 재질 23자리를 파일 10개로, 스킬 19가지를 15갈래로. 파일이 없어도 합성음이 갈립니다 |
| **판정과 그림이 같은 것을 말해야 한다** | 문이 **닫혔을 때** 얇은 막대 하나로, **열렸을 때** 널판 한 장으로 그려지고 있었습니다. 길은 막혔는데 화면에는 틈이 훤하고, 지나갈 수 있는데 화면에는 문이 서 있었습니다. 이런 것은 한 번 배우고 나면 플레이어가 **그림 보기를 그만둡니다** — 상태를 그림으로 내보내는 곳은 반드시 실제로 열고 닫아 보며 확인합니다 |

### 2-5. 그림의 규칙

- **원본에서 빼거나 옮겨서 만든다. 더해서 만들지 않는다.** 덧붙인 부분은
  패치처럼 보입니다. 성근 잎판도, 쓰러지는 칸도 전부 원본을 깎아 만들었습니다.
- **알파로 거리를 표현하지 않는다.** 투명해진다는 것은 뒤가 비친다는 뜻이라
  하늘의 해와 달이 원경 나무를 뚫고 나왔습니다. 멀리 있는 것은 **공기 색에
  씻겨서** 흐린 것이므로 색으로 물들입니다.
- **칸에 부딪히면 잘린다.** 변형(기울임·늘림)을 걸 때는 남은 여백을 먼저 재고
  그만큼만 겁니다(`tools/clipcheck.py` 가 잡아냅니다).
- **스케치 좌표를 그대로 옮기면 틀을 넘는다.** 64x64 viewBox 스케치를 64칸 시트에
  그대로 옮기면 가장 큰 프레임이 틀에 붙습니다 — 넘은 자리는 없어지는 것이 아니라
  **잘린 단면으로 남습니다.** 굽는 과정을 두 번으로 나눠, 넓은 판에 잘리지 않게
  한 번 그려 재고 그 배율로 다시 그립니다(`tools/mkhitphys.py`). 배율은
  **시트 하나에 하나** — 프레임마다 맞추면 애니메이션이 프레임 단위로 커졌다
  작아집니다. 그리고 줄어든 만큼 **화면에서 그리는 크기를 나눠서 올립니다**
  (`HIT_FX.size`). 틀에 맞추느라 작아지면 고친 것이 아니라 바꾼 것입니다.
- **부르지 않는 애셋보다 나쁜 것은 보이지도 않는데 부르는 애셋이다.**
  `parallax_works` 는 아무 데서도 안 불리고 있었는데, 불러 봤더니 **한 픽셀도
  화면에 안 닿았습니다** — 원경은 벽지(walls)보다 먼저 깔리고, 세 시드에서 세어 보니
  지하의 빈 칸 9만 7천 개 중 벽지 없는 칸이 0개였습니다(`parallax_hell` ·
  `parallax_ruin` 도 같습니다). 그래서 셋 다 매 프레임 두 층을 깔고 색을 굽고는
  통째로 덮이고 있었습니다.
  **애셋을 붙이기 전에 "그 자리에서 실제로 보이는가"를 먼저 셉니다** — 타일과
  벽지를 훑어 빈 칸 비율을 재는 것이 스크린샷보다 확실합니다. 그리고 안 보이는
  것을 보이게 만드는 쪽이 분위기를 해치면(땅속은 갇혀 있다는 것 자체가 분위기라
  바위 너머로 먼 하늘이 비치면 바깥으로 뚫린 구멍이 됩니다) **그림은 남기고 부르지
  않습니다.** 지금 실제로 보이는 원경은 지상·하늘 섬·여명 마을뿐입니다.

### 2-6. 값과 경제

- **캘 수 있으면 캐는 쪽이 값을 정한다.** 만들 수도 있는 것이라도 그렇습니다.
  도시가 통째로 강철판인데 강철판을 벼려서 값을 매기면 벽을 뜯는 것이 무한한
  금화가 됩니다.
- **만들면 값이 붙는다.** 조리법의 재료값 합보다 완제품이 싸면 벼릴수록
  가난해집니다. 새 조리법을 넣으면 배율을 확인합니다(지금 중앙 1.32).
- **보상은 레벨을 따라간다.** 경험치는 그 레벨의 필요 경험치(`40·lv^1.42`)를
  기준으로 매깁니다. 레벨에 1차로 붙이면 후반에 반드시 뒤처집니다.

### 2-7. 이름과 저장

- **객체 리터럴에서 같은 키를 두 번 쓰면 뒤엣것이 이깁니다.** `burst()` 를
  두 번 정의해 타격 이펙트가 통째로 사라진 적이 있습니다. 메서드를 더할 때는
  이름을 먼저 찾아봅니다.
- **저장에 들어가는 것은 전부 직렬화 가능해야 합니다.** 함수를 담으면 불러올 때
  사라집니다. 계산으로 낼 수 있는 값은 저장하지 말고 그때그때 셉니다
  (의뢰 보상이 그렇습니다 — 굳혀 두면 레벨이 올라도 옛 값을 받습니다).
- **옛 저장을 읽을 길을 남깁니다.** 모양이 바뀐 데이터는 감지해서 새로 만들거나
  기본값으로 떨어뜨립니다.

### 2-8. 배포

- `tools/build-site.sh` 는 **커밋되는 원본 두 파일을 제자리에서 고칩니다**
  (`?v=dev` → 커밋 해시). 로컬에서 돌린 뒤 그대로 커밋하면 판 번호가 소스에
  박힙니다. 스크립트가 끝에 되돌리는 법을 찍습니다.
- 애셋을 고치면 `?v=` 를 올립니다. 안 올리면 **고친 사람 눈에만** 반영됩니다.

## 3. 세션 3 을 시작할 때

### 3-1. 이미 준비된 것

아래는 **표에 줄만 더하면** 세션 3 에서 그대로 동작합니다. 코드를 고칠 필요가
없습니다 — 이번 v1.1 에서 전부 표로 옮겨 두었습니다.

의뢰 게시판 · NPC 부탁 · 물건값 · 재질 소리와 파편 · 스킬 손맛 ·
보스가 쓰러지는 연출 · 잿빛(원한다면 새 곡선) · 일지의 세션 탭 ·
상황 대사(TALK) · 장별 대사(DIALOGUE)

### 3-2. 새로 만들어야 하는 것

| | |
|---|---|
| 바이옴 | `world.js` 의 지형 생성. **폭은 못 늘립니다** — 지금 4200 안에서 자리를 냅니다 |
| 원경 그림 | 바이옴마다 한 장. 없으면 숲 배경으로 떨어집니다 |
| 타일 텍스처 | 절차 생성(`tileart.js`)이든 손그림(`TILE_SPRITE`)이든 |
| 몹·보스 시트 | 규격은 `docs/v1.1-changelog.md` 와 `tools/` 의 굽는 스크립트들 |
| 유적 | 세션마다 유적을 두는 것이 이 게임의 결입니다. 고유 몹 하나 · 장식 둘 · 전리품 둘 |

### 3-3. 이야기를 쓸 때의 결

세션 1 은 **꿈**이었고(별 조각이 잘못 꾼 꿈이 세계를 잊게 한다),
세션 2 는 **멈추지 못함**이었습니다(멈출 권한은 있는데 멈출 이유를 배우지 못함).
둘 다 악당이 없습니다 — 잘못 꾼 것과 배우지 못한 것이 있을 뿐입니다.

그 결을 이어받는다면 세션 3 도 **적이 아니라 상태**를 놓고 씁니다.
세션 2 의 마지막이 남긴 실마리가 그대로 문입니다:

> 『당신들은 만들다 만 것이 아닙니다. 당신들은 그 다음입니다.』
> — 원형, 세션 2 종장

## 4. 되먹임 — 이 문서를 고치는 때

| 이럴 때 | 이렇게 |
|---|---|
| 세션 3 작업 중 **같은 자리에 두 번 걸렸다** | 2절에 줄을 더한다. 그 커밋에 같이 넣는다 |
| 세션 3 에서 **새 표를 만들었다** | 1-1 표에 줄을 더한다 (다음 세션이 또 빠뜨린다) |
| v1.1 쪽에서 **규칙을 바꿨다** | 2절을 고치고 changelog 에도 적는다 |
| 1절 목록대로 했는데 **빠진 자리가 있었다** | 그 자리를 1절에 더한다. 목록이 틀린 것이 목록이 없는 것보다 나쁘다 |

문서가 코드보다 늦으면 아무도 안 봅니다. **표를 하나 만들면 그 자리에서 1절에
줄을 더하는 것**이 유일하게 지켜지는 방법입니다.
