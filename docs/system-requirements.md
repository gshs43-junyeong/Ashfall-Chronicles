# 시스템 요구사항

이 게임은 **브라우저 안에서** 돕니다. 웹(`/play`)으로 열든 zip 을 받아 열든 같습니다 —
받는 판도 로컬 웹 서버를 띄우고 기본 브라우저를 열 뿐입니다. 그래서 요구사항의 중심은
기기가 아니라 **브라우저**입니다.

숫자는 전부 재서 나온 것입니다. 근거는 3절에 있습니다.
Steam 으로 낼 때(= Chromium 을 싸서 실행 파일로 만들 때)는 5절이 따로 있습니다.

## 1. 브라우저로 열 때

### 1-1. 브라우저 (여기가 진짜 문턱입니다)

| | 최소 | 권장 |
|---|---|---|
| **Chrome · Edge** | 99 이상 (2022-03) | 111 이상 (2023-03) |
| **Firefox** | 97 이상 (2022-02) | 113 이상 (2023-05) |
| **Safari** | 16 이상 (2022-09) | 16.2 이상 (2022-12) |
| **그래픽 가속** | **켜져 있어야 합니다** | 〃 |

- **최소선을 정한 것은 캔버스의 `roundRect`** 입니다. 몹 이름표를 그릴 때 쓰는데 두 곳이
  대비 없이 부르고 있어서(`game.js` 5824·5856), 없는 브라우저에서는 그 자리에서 멈춥니다.
- **권장선을 정한 것은 CSS 의 `color-mix()`** 입니다(테두리 광택 8곳). 없어도 **게임은
  그대로 돕니다** — 창 테두리의 은은한 빛만 안 납니다.
- **그래픽 가속이 꺼져 있으면 못 씁니다.** 브라우저 판에서 "왜 느리냐"의 대부분이
  이것입니다. Chrome·Edge 는 `설정 → 시스템 → 가능한 경우 그래픽 가속 사용`,
  Firefox 는 `설정 → 성능 → 권장 성능 설정 사용`. 실측으로 가속이 없으면 1080p 가
  **16fps** 입니다.

### 1-3. 네트워크와 저장

| | |
|---|---|
| **첫 방문 내려받기** | **7.5 MB** (요청 453개) — 그림 4.1 MB · 효과음 2.0 MB · 스크립트 1.4 MB |
| **배경음** | 8곡 53.6 MB. **부팅에 안 받고 틀 때만 흘러옵니다**(한 곡 약 6.7 MB) |
| **첫 방문 여는 시간** | 100 Mbps **3.9초** · 25 Mbps **5.0초** · 10 Mbps **8.9초** · 4 Mbps **20.5초** |
| **재방문** | 망 속도와 무관하게 **약 1초** (판 번호로 캐시가 물립니다) |
| **저장 자리** | 슬롯당 **955 KB**(갓 시작) ~ **2.0 MB**(세계를 다 파헤친 뒤) |
| **저장 한도** | 브라우저의 `localStorage` — 실측 약 **4 MB** |

> ★ **슬롯 셋을 전부 끝까지 채우면 한도에 닿습니다.** 최악의 경우 3 × 2.0 MB = **5.97 MB**
> 인데 브라우저가 주는 자리는 약 4 MB 입니다. 그때는 게임이 「저장 실패: 용량 초과」를
> 띄웁니다(조용히 날아가지는 않습니다). 안 쓰는 슬롯을 지우거나, 설정의
> **「저장 내보내기」**로 파일에 빼 두세요.

## 2. 안 되는 것 · 주의할 것

| | |
|---|---|
| **휴대폰 · 태블릿** | 안 됩니다. 터치 입력을 받지 않습니다 — 키보드가 있어야 움직입니다 |
| **게임패드** | 안 받습니다 |
| **사생활 보호 모드(시크릿)** | **창을 닫으면 저장이 사라집니다.** 저장은 그 브라우저의 `localStorage` 에만 있습니다 |
| **브라우저를 바꾸면** | 이어지지 않습니다. Chrome 에서 하던 것을 Safari 에서 열면 새 여정입니다 |
| **"방문 기록·사이트 데이터 삭제"** | 저장이 같이 지워집니다 |
| **탭을 많이 띄워 두면** | 메모리가 모자랄 때 브라우저가 **이 탭부터** 버립니다(400 MB 짜리라서). 돌아오면 다시 읽습니다 |

## 3. 이 숫자가 어디서 나왔나

재는 조건이 **GPU 없는 컨테이너의 소프트웨어 래스터라이저**라 프레임 시간은 실제 기기보다
나쁜 쪽입니다 — 사양을 낮춰 잡지 않으려고 그대로 씁니다.

| 재는 것 | 값 | 어떻게 쟀나 |
|---|---|---|
| 첫 방문 전송량 | **7.5 MB** / 요청 453개 | 응답 `content-length` 합산 |
| └ 갈래별 | PNG 364개 4.05 MB · MP3 74개 2.02 MB · JS 13개 1.35 MB · CSS 0.05 MB | 〃 |
| 여는 시간 | 100/25/10/4 Mbps → **3.9 / 5.0 / 8.9 / 20.5초**, 재방문 **약 1초** | CDP 로 망을 조여서 측정 |
| 그림이 **메모리에서** | **376 MB** (디코딩 362장) | `naturalWidth×naturalHeight×4` 합산 |
| └ 그중 보스 시트 다섯 | **164 MB** (복원자 11328×1056 한 장이 45.6 MB) | 〃 |
| JS 힙 | 14~19 MB | `performance.memory` |
| 세계 배열 | 5.8 MB (4200×480 × 3벌 + 빛 버퍼) | 배열 길이 합산 |
| 세계 생성(로딩) | **4.8 ~ 5.9초** | `new World(seed).generate()` 세 번 |
| 프레임 시간 p50 | 720p **29.4 ms** · 1080p **63.3 ms** · 1440p **108.8 ms** | 180프레임 |
| 몹 40마리를 더 부른 뒤 | 29.4 → **31.4 ms** (720p) | 〃 |
| 저장 | 갓 시작 **955 KB** · 최악 **2,037 KB** | 저장 후 `localStorage` 길이 |
| 저장 한도 | 약 **4 MB** (`QuotaExceededError` 까지 채워서) | 64 KB 씩 넣어 보다 터지는 지점 |
| 디스크 | 게임 폴더 61 MB — 소리 53.6 MB(43개) · 그림 4.2 MB(PNG 375장) | `du` |

### 숫자에서 사양이 나오는 방식

- **메모리 4 GB** — PNG 는 디스크에서 4.2 MB 지만 화면에 올리려면 **RGBA 로 펴야** 하고,
  그게 376 MB 입니다(보스 시트 하나가 11328×1056). 거기에 JS 힙·세계 배열·캔버스 버퍼가
  붙어 탭 하나가 약 400 MB 입니다.
- **그래픽에 "가속 여부"만 요구** — 셰이더도 WebGL 도 3D 도 안 씁니다. Canvas 2D 의
  `drawImage` 뿐이라 요구하는 것은 성능이 아니라 **가속이 켜져 있는가**입니다.
- **몹을 마흔 더 불러도 2 ms 밖에 안 늘었습니다** — 병목이 개체 수가 아니라 **채우는
  픽셀 수**라는 뜻이고(1440p 가 1080p 의 1.7배), 그래서 CPU 보다 **해상도**가 사양을 가릅니다.
  창을 줄이거나 설정의 「시야 범위」를 **올리면**(좁게 보임) 가벼워집니다.
- **4코어 권장은 코어를 써서가 아닙니다.** 게임은 싱글 스레드고, 줄여야 하는 것은 로딩
  5초라 사실상 단일 코어 성능의 표시입니다.
- **첫 방문 7.5 MB 뿐인 까닭** — 53.6 MB 인 배경음을 부팅에 안 받기 때문입니다.
  그림은 PNG 가 잘 눌려서(4.2 MB) 전부 받아도 가볍습니다.

## 5. 부록 — Steam 으로 낼 때

지금 판은 로컬 웹 서버를 띄우고 기본 브라우저를 여는 방식이라 **Steam 에 그대로 못
올립니다.** 실제 게임이 다른 프로그램 안에서 돌아서 오버레이·플레이 시간·업적·컨트롤러가
전부 안 붙습니다. **Chromium 을 함께 싸서 실행 파일 하나로** 만들어야 합니다.

| 싸는 방식 | 런타임 용량 | 영향 |
|---|---|---|
| **Electron** | +180~200 MB | 브라우저를 같이 들고 다녀 어디서나 같은 그림이 나온다 |
| Tauri / WebView2 | +10 MB | 용량은 줄지만 **OS 의 웹뷰 판에 따라 그림·소리가 갈린다** |

그 경우 1절의 브라우저 줄이 빠지고 아래가 붙습니다.

| | 최소 | 권장 |
|---|---|---|
| **운영체제** | Windows 10 64-bit (1809+) · macOS 11 · Ubuntu 20.04 / SteamOS 3 | Windows 11 · macOS 13+ · Ubuntu 22.04 |
| **DirectX** | 버전 11 | 버전 11 |
| **저장 공간** | **500 MB** (실제 설치 ≈ 콘텐츠 61 MB + 런타임 190 MB) | 500 MB |

프로세서·메모리·그래픽·해상도는 1-2 절과 같습니다.

### Steam Deck

해상도로는 여유가 있습니다(1280×800 은 1080p 픽셀의 **59%**). 다만 지금은 Verified 가
아니라 **Playable** 이 정직합니다 — 게임패드를 안 받아 Steam Input 레이아웃을 따로 만들어야
하고, UI 글꼴이 11~12px 이라 7인치에서 읽기 힘듭니다(설정의 「시야 범위」는 세계만 키우고
UI 는 안 키웁니다).

## 6. 사양을 다시 재야 할 때

| 바뀌는 것 | 다시 봐야 하는 줄 |
|---|---|
| 보스 시트를 더 큰 것으로 다시 굽는다 | **메모리** — 다섯 장이 이미 164 MB 다 |
| 효과음 파일 36개를 채운다 | **첫 방문 전송량** — 지금 MP3 2.0 MB 에서 늘어난다 |
| 새 바이옴·유적을 더한다 | **세계 생성 시간**(로딩 5초) · **저장 크기** |
| `WW`·`WH` 를 늘린다(지금은 금지) | **메모리** · **세계 생성** · **저장 한도** |
| 게임패드·터치를 받는다 | 2절과 5절(Steam Deck) |
| `roundRect` 두 곳에 대비를 붙인다 | **최소 브라우저**가 Safari 16 → 14 로 내려간다 |

재는 방법은 `docs/story-and-sessions.md` 2-3 절("눈으로 보지 말고 잰다")과 같습니다 —
브라우저에서 전송량·`performance.memory`·`World.generate()` 시간·180프레임 프레임 시간을
그 자리에서 재서 표를 갈아 끼웁니다.
