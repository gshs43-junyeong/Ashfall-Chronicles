# Ashfall Chronicles v1.1.3 — 타오르는 불길

**v1.1.x 의 저장은 그대로 열립니다.** 하늘 섬 · 나무 배치가 조금 바뀌어 새로 만드는 세계만 달라집니다.
릴리스 본문은 영어판 [`v1.1.3-changelog.md`](v1.1.3-changelog.md) 입니다 — 하나를 고치면 둘 다.

내려받는 판은 v1.1.2 와 같습니다 — 브라우저로 여는 판(`AshfallChronicles-1.1.3-Windows.zip` · `-macOS.zip`)과 앱으로 여는 판
(`…-App-Windows.zip` · `-App-macOS-AppleSilicon.zip` · `-App-macOS-Intel.zip` · `-App-Linux.zip`).

둘 다 개발자 인증서로 서명하지 않아 처음 한 번 운영체제가 묻습니다 — **Windows** *추가 정보 → 실행* ·
**macOS 14 · 15** "악성 코드가 없음을 확인할 수 없습니다" 창에서 **완료**(휴지통으로 이동을 누르면 앱이 지워집니다) →
*시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기*. Apple 유료 공증을 받지 않은 앱이면 모두 뜨는 창입니다.
창 없이 열려면 터미널에서 `xattr -dr com.apple.quarantine "/Applications/Ashfall Chronicles.app"`.

## 새로

- **새로 그린 스킬 연출.** 칼선 · 충격파 · 섬광 · 룬이 새겨진 마법진 · 빛기둥 · 빛줄기 · 연기를 원과 선 대신 구운 결 그림으로 — 갈래 색으로 물든다.
- **불이 붙는다.** 불에 맞은 몬스터는 몸 윤곽 안이 달아오르고 불길이 몸을 타고 오른다. 얼어붙은 몬스터는 네모 상자 대신 윤곽째 언다.
- **떠 있는 몬스터.** 박쥐 · 망령 · 점프 중인 몸에 허공의 바닥 선을 긋지 않고, 불길 · 서리 · 시전 빛 · 북돋움 기운이 몸을 따라 붙는다.
- **깡충 뛰는 토끼.** 들토끼 · 눈산토끼가 제자리에서 둠칫거리지 않고 깡충 뛰어 다닌다.
- **세계.** 베이스캠프 · 여명 마을 위에는 하늘 섬이 생기지 않고, 채취탑 둘레 나무는 수관이 잘리거나 잎만 떠 남지 않는다.
- **새 모습.** 아치를 뺀 가벼운 타이틀 로고, 새 탭 아이콘으로 바뀐 앱 아이콘, 다운로드 페이지의 앱 판 실행 안내.

## 고침

- 스킬 불(유성우 따위)에 맞은 몬스터가 피해는 받는데 불이 안 붙어 보이던 것.
- 앱으로 여는 판에 옛 아이콘이 들어가던 것.
