# 낚시를 화면에 보이게 하는 법 — 구상만

**이 문서의 내용은 리포지토리에 들어가 있지 않습니다.** 한 번 만들었다가
되돌렸습니다 — v1.1 로컬 작업에 이미 낚시 수정이 들어가 있어서, 같은 파일 같은
함수를 양쪽에서 고치면 병합이 지저분해지기 때문입니다.
아래는 **무엇이 문제였고 어떻게 고치면 되는가**입니다. v1.1 쪽 낚시 코드에 맞춰
골라 쓰시면 됩니다.

---

## 1. 무엇이 문제인가

낚시는 지금 **글자로만 돌아갑니다.**

```
우클릭 → 토스트 "낚싯줄을 드리웠다"
   (대기 1.2~2.8초 × 낚싯대 배율 — 화면에 아무것도 없음)
→ 토스트 "손끝이 흔들린다!" + 입질 순간 파티클 10개
→ 우클릭 → 토스트 "낚았다 — 은빛 물고기"
```

화면에 그려지는 것은 **입질 순간의 파티클 열 개가 전부**입니다.

- 어디에 던졌는지가 화면에 없습니다. 겨눈 물 칸은 `p.fish.tx/ty` 로 코드만 압니다.
- 낚싯대는 손에 그려지는데(v1.0.5에서 넣었습니다) **줄이 안 나갑니다.**
  대만 들고 서 있는 그림입니다.
- 입질을 토스트로만 알립니다. 토스트는 화면 위쪽에 뜨고 물은 아래쪽에 있어서,
  물을 보고 있으면 입질을 놓칩니다.
- 홈페이지 기능 소개 아홉 칸의 첫 칸이 "낚시"인데, 스크린샷을 찍을 그림이 없습니다.

## 2. 무엇을 그리면 되는가

**줄 · 찌 · 물결 · 입질 표시** 넷이면 됩니다. 새 애셋은 필요 없습니다 — 전부
캔버스 도형입니다.

| 요소 | 평소 | 입질 중 |
|---|---|---|
| 줄 | 대 끝 → 찌, 살짝 늘어진 곡선 (회백색, 알파 0.7) | 팽팽하게 곧게, 밝게 (알파 0.95) |
| 찌 | 물결 따라 ±1.3px 느리게 까딱임 | 3~6px 아래로 쑥, 빠르게 떨림 |
| 물결 | 찌 자리에서 천천히 번지는 타원 두 겹 (푸른빛) | 빠르게·크게·금빛 |
| 입질 표시 | 없음 | 찌 위에 느낌표 하나, 깜빡임 |

여기에 **줄을 걷는 순간 물 튀김**(파티클 7개, 챔질이면 14개 + `splash` 소리)을
더하면 "잡았다"가 손끝에 옵니다.

## 3. 어디에 넣는가

### 3-1. 그리기

`G.render()` 의 `this.drawPlayer(...)` **바로 뒤**에 한 줄:

```js
this.drawFishing(c, p, camX, camY);
```

> **그리는 순서**는 취향입니다. `drawPlayer` 뒤 · `drawLightOverlay` 앞에 두면
> 밤에는 찌도 같이 어두워져서 자연스럽습니다. 반대로 조명 뒤로 빼면 밤에도
> 입질 표시가 또렷하게 보입니다. 저는 **앞**에 뒀는데, 밤낚시에서 찌가 잘 안
> 보인다면 뒤로 옮기는 쪽이 낫습니다.

### 3-2. 메서드

`p.fish` 는 이미 필요한 것을 다 들고 있습니다 —
`{ tx, ty, t, biting, bite, rodId, rareMul }`. **새 상태값이 필요 없습니다.**

```js
/** 드리운 낚싯줄 · 찌 · 물결 */
drawFishing(c, p, camX, camY) {
  const f = p.fish; if (!f) return;
  const bx = (f.tx + 0.5) * TS - camX;
  const wy = f.ty * TS - camY;
  const t = this.time;
  // 찌는 평소엔 물결 따라 까딱이고, 입질 중엔 쑥 잠겼다 튀어오른다
  const bob = f.biting
    ? Math.sin(t * 26) * 3.4 + 3
    : Math.sin(t * 2.4 + f.tx * 0.7) * 1.3;
  const by = wy + bob;
  const hx = p.cx - camX + p.facing * 9, hy = p.cy - camY - 8;   // 낚싯대 끝
  c.save();
  // 줄 — 입질 중엔 팽팽해지고, 아니면 살짝 늘어진다
  c.strokeStyle = f.biting ? '#fff1c8' : '#cfd6dd';
  c.globalAlpha = f.biting ? 0.95 : 0.7;
  c.lineWidth = 1;
  c.beginPath();
  c.moveTo(hx, hy);
  c.quadraticCurveTo((hx + bx) / 2, (hy + by) / 2 + (f.biting ? 0 : 7), bx, by);
  c.stroke();
  // 물결 — 찌가 앉은 자리에서 번져 나간다
  c.strokeStyle = f.biting ? '#ffd98a' : '#9fd0e8';
  for (let i = 0; i < 2; i++) {
    const ph = ((t * (f.biting ? 1.9 : 0.75) + i * 0.5) % 1);
    c.globalAlpha = (1 - ph) * (f.biting ? 0.6 : 0.35);
    c.beginPath();
    c.ellipse(bx, wy + 1, 3 + ph * (f.biting ? 15 : 10), 1 + ph * (f.biting ? 4 : 3), 0, 0, TAU);
    c.stroke();
  }
  // 찌
  c.globalAlpha = 1;
  c.fillStyle = '#c8433c';
  c.beginPath(); c.arc(bx, by - 2, 2.6, 0, TAU); c.fill();
  c.fillStyle = '#e8e3d4';
  c.fillRect(bx - 0.6, by - 6, 1.4, 4);
  if (f.biting) {                                   // 입질 — 느낌표 하나
    c.globalAlpha = 0.6 + 0.4 * Math.sin(t * 18);
    c.fillStyle = '#ffe08a';
    c.fillRect(bx - 1, by - 17, 2, 6);
    c.fillRect(bx - 1, by - 9, 2, 2);
  }
  c.restore();
}
```

### 3-3. 줄을 걷을 때 물 튀김

`resolveFish()` 안에서 **`p.fish = null;` 바로 앞**에 (자리를 지우기 전에 챙겨야 합니다):

```js
const wx = (p.fish.tx + .5) * TS, wy = p.fish.ty * TS;
for (let i = 0; i < (quality === 'reel' ? 14 : 7); i++)
  this.parts.push(new Part(wx, wy, '#cfe8ff', -40 - Math.random() * 40, .55));
this.sfx('splash');
p.fish = null;
```

`splash` 는 이미 `sfx` 표에 있습니다(캐스팅에서 씁니다).

## 4. ★ v1.1 낚시 수정과 겹칠 만한 곳

| 겹칠 곳 | 확인할 것 |
|---|---|
| `p.fish` 의 필드 이름 | 위 코드는 `tx · ty · biting` 셋만 읽습니다. v1.1에서 구조를 바꿨으면 그 세 값에 해당하는 것으로만 갈아 끼우면 됩니다. |
| `tryFish()` / `resolveFish()` | 물 튀김은 `resolveFish` 안 한 곳만 건드립니다. v1.1이 이 함수를 갈아엎었다면 "줄을 걷는 지점"에 그대로 옮기세요. |
| `render()` 의 그리기 순서 | 호출 한 줄뿐입니다. 3-1의 순서 메모를 보세요. |
| 낚싯대 끝 좌표 | 지금은 `p.cx ± 9, p.cy − 8` 로 근사했습니다. v1.1에서 낚싯대를 겨눔 방향으로 돌리게 했다면(활처럼) 그 각도를 써서 진짜 대 끝을 잡는 편이 낫습니다 — `drawHeldWeapon` 의 활 분기(`BOW_HAND`)와 같은 방식입니다. |
| 물 물리 변경(v1.1 항목) | 수영·산소가 들어가면 수면 높이 판정이 달라질 수 있습니다. 찌는 `f.ty * TS`(겨눈 물 칸의 윗변)에 앉습니다 — 수면이 칸 안에서 오르내리게 바뀌면 그 값을 쓰세요. |

## 5. 더 나아가려면 (선택)

지금 낚시는 **기다렸다 누르기** 하나뿐입니다. 위의 것은 "보이게" 하는 데까지고,
"재미있게"는 별개입니다. 넣는다면 이 순서를 추천합니다.

1. **물고기 그림자** — 입질 1초쯤 전에 찌 쪽으로 다가오는 어두운 타원 하나.
   기다리는 시간이 죽은 시간이 아니게 됩니다. 코드 몇 줄이고 상태값도 필요 없습니다
   (`f.t` 가 얼마 남았는지로 계산).
2. **챔질 타이밍 창** — 지금 `bite` 창 안에 누르면 보너스가 붙는데, **그 창이
   화면에 없습니다.** 찌 위에 짧은 게이지 하나만 그려도 "지금!"이 생깁니다.
3. **버티기** — 큰 것이 걸리면 좌우로 끌려다니고, 줄이 팽팽할 때 놓아 줬다
   당겼다 해야 올라오는 식. 이건 새 상태와 조작이 필요해서 별도 작업입니다.
4. **자리마다 다른 물** — `w.pools` 의 `rareMul` 은 이미 자리마다 다른데
   화면에는 티가 안 납니다. 좋은 웅덩이는 물빛이나 물결을 달리 하면 "여기가 잘
   나온다"를 눈으로 익히게 됩니다.

1·2번은 위의 `drawFishing` 에 얹는 정도라 같이 해도 부담이 없습니다.
