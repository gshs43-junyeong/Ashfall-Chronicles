# v1.1 — 필요한 효과음과 생성 프롬프트

만들어야 할 효과음 목록과, ElevenLabs(<https://elevenlabs.io>)에 그대로 넣을 수 있는
영어 프롬프트. 프롬프트는 영어로 두고 설명만 한국어다.

## 넣는 법

1. 받은 파일을 `game/assets/sound_effects/<이름>.mp3` 로 둔다.
2. `game/js/music.js` 의 `SFX_FILES` 에 `키: '파일이름'` 한 줄을 더한다.
   (키와 파일 이름이 같으면 `키: '키'` 로 적는다 — 표가 그렇게 생겼다.)
3. 자주 겹쳐 울리는 소리는 `SFX_GAP` 에 최소 간격(초)을, 상시로 깔리는 소리는
   `SFX_VOL` 에 음량 배수를 적는다.
4. 파일이 없으면 `game.js` 의 `sfx()` 가 합성음으로 대신 울리므로 **한 개씩 넣어도**
   게임은 그대로 돈다. 급한 것부터 넣으면 된다.

## 공통 규칙

| | |
|---|---|
| 형식 | MP3 · 44.1kHz · 모노로 충분 |
| 앞 공백 | **없어야 한다.** 앞에 정적이 붙어 오면 `SFX_START` 로 잘라 쓸 수는 있지만(hatch 가 1.60초로 그렇게 쓰고 있다) 없는 게 낫다 |
| 꼬리 | 타격·채굴은 200ms 안에 끝난다. 길게 울리면 연타할 때 진창이 된다 |
| 음량 | 최대 진폭 -3dB 정도로 맞추고, 게임 안에서 `SFX_VOL` 로 낮춘다 |
| 음악 금지 | 프롬프트에 `no music, no melody, dry, close-miked` 를 붙인다. 안 붙이면 톤이 붙어 나온다 |

# C. 타격 — 무기 계열 × 치명타

지금은 근접·활·마법이 각각 `swing`·`bow`·`magic` 을 쓰는데, 이건 **휘두르는 소리**지
**맞는 소리**가 아니다. 맞는 순간에는 아무 소리도 안 난다(피격자의 `damage` 만 울린다).
손맛이 얇게 느껴지는 가장 큰 이유다.

## C-1. 원칙 — 치명타는 따로 만들지 않는다

무기 계열마다 평타·치명타 두 벌을 만들면 개수가 두 배가 되고, 두 소리가 서로 다른
악기처럼 들려 오히려 따로 논다. **평타 소리 위에 치명타 한 겹(`hit_crit`)을 얹는다.**

```js
G.sfx('hit_' + fam);              // 늘 울린다
if (crit) G.sfx('hit_crit');      // 치명타일 때 한 겹 더
```

`hit_crit` 은 그 자체로는 무기 소리가 아니라 **강조**다 — 짧고 높고 금속적이며,
어느 계열 위에 얹어도 섞인다.

# D. 재질 — 열 개

## D-0. 왜 열 개인가

처음에는 재질마다 닿는 소리(`hit_*` 열하나)와 부서지는 소리(`break_*` 열둘)를
따로 두려고 했다. **파일 스물세 개는 과했다.**

부서지는 소리는 대개 **닿는 소리의 큰 판**이다. 돌을 때리는 톡 소리와 돌이
떨어져 나가는 와르르 소리는 결이 같고 크기와 길이만 다르다. 그래서 재질 열둘을
결이 같은 것끼리 **열 갈래**로 묶고, 닿는 것과 부서지는 것은 **같은 파일을
다르게 틀어서** 가른다 — 부수는 쪽은 음을 낮추고 크게. 어느 키가 어느 파일을
어떤 배수로 쓰는지는 `game/js/music.js` 의 `SFX_FAM` 에 적혀 있다.

| 파일 | 덮는 재질 | 어디서 |
|---|---|---|
| `mat_stone` | 돌 (+ 적어 두지 않은 것 전부) | 바위·벽돌·광맥 |
| `mat_dirt` | 흙 | 흙·모래·재·잔디 |
| `mat_wood` | 나무 | 통나무·판자·발판 |
| `mat_metal` | 쇠 (+ 기계가 부서질 때) | 광물 블록·기계·강철판 |
| `mat_glass` | 유리 · 얼음 | 수정·에테르·얼음 |
| `mat_plant` | 풀 | 잎·덩굴·버섯·작물 |
| `mat_flesh` | 살 · 젤 | 몹 대부분 |
| `mat_bone` | 뼈 | 해골 몹·뼈 무더기 |
| `mat_ember` | 불티 | 용암·지옥석·임프 |
| `mat_void` | 공허 | 망령·부패한 땅 |

## D-1. 만들 때 지킬 것

이 열 개는 **두 번 쓰인다** — 그대로(닿는 소리), 그리고 음을 0.7~0.85배로
낮추고 1.35~1.45배로 키워서(부서지는 소리). 그래서:

* **앞이 분명할 것.** 시작하자마자 때리는 점이 있어야 느리게 틀어도 뭉개지지 않는다.
* **꼬리가 짧을 것.** 0.15~0.25초. 늘여 틀어도 다음 타격을 안 먹는다.
* **음정이 없을 것.** 음이 있으면 배수로 틀 때 조가 바뀐 것으로 들린다.
* 건조하게, 잔향 없이, 음악 없이. 가까이서 녹음한 것처럼.

게임이 재생할 때마다 음높이를 ±6% 더 흔들기 때문에(`playbackRate`) 한 획마다
조금씩 다르게 들린다 — 프롬프트에 변주를 넣을 필요가 없다.

## D-3. 파일이 없어도 소리는 갈린다

`game/js/game.js` 의 `sfx()` 안에 **스물세 가지** 합성음 규격이 들어 있다 —
시작·끝 주파수, 파형, 크기, 잡음 섞는 정도. 그래서 **파일을 한 개도 안 넣은
지금도 재질마다 다르게 들린다.** 합성음은 코드라 공짜여서 이쪽은 줄이지 않았다.

파일을 열 개 넣으면 그 열 개가 스물세 자리를 전부 채운다. 하나씩 넣어도 된다 —
넣은 것만 파일로 울리고 나머지는 계속 합성음이다.

파일을 넣을 때는 `game/js/music.js` 의 `SFX_FILES` 안에 주석으로 적어 둔 줄을
풀면 된다.

| 4 | `mat_ember` · `mat_void` — 특정 구역에서만 |

> C 절의 `hit_slash` · `hit_blunt` · `hit_pierce` 는 **무기 쪽** 축이라 이 재질
> 축과 겹치지 않는다. 다만 한 타격에 두 파일을 겹쳐 트는 것은 아직 안 한다 —
> 지금은 재질 쪽만 울린다. 무기 축까지 넣으려면 그때 `sfx()` 를 두 번 부르고
> 음량을 나누면 된다.

# E. 스킬 — 열아홉 가지를 열다섯 갈래로

## E-1. 왜 이게 필요했나

`useSkill()` 은 마지막에 `G.sfx('skill')` 한 줄로 끝났다. 화염구도, 치유도,
순간이동도, 전투 함성도, 사슬 번개도 **똑같은 삑 소리 하나**였다. 무엇을
썼는지가 소리로는 전혀 안 들렸고, 그래서 스킬 넷을 돌려 쓰는 손이 "네 가지를
쓰는 손"이 아니라 "쿨다운을 세는 손"이 됐다.

열아홉 가지를 갈래로 묶었다. 베기와 검무는 같은 칼바람이고, 화염구와 운석은
같은 불이 붙는 소리다(운석이 **닿는** 순간만 따로 크게). 그래서 **파일은
열다섯 개**면 된다. 어느 스킬이 어느 갈래인지는 `game/js/data.js` 의
`SKILL_FX` 에 적혀 있다.

| 갈래 | 쓰는 스킬 |
|---|---|
| `sk_slash` | 광폭 베기 · 회오리 검무 |
| `sk_whirl` | 회오리 검무가 도는 동안(0.28초 박자) |
| `sk_charge` | 돌진 강타 |
| `sk_quake` | 대지 가르기 |
| `sk_guard` | 철벽 |
| `sk_shout` | 전투 함성 |
| `sk_volley` | 화살 세례 · 유성 화살비 |
| `sk_pierce` | 꿰뚫는 화살 |
| `sk_smoke` | 연막탄 |
| `sk_mark` | 사냥꾼의 표식 |
| `sk_fire` | 화염구 · 별의 낙하(시전) |
| `sk_meteor` | 별의 낙하(닿는 순간) |
| `sk_frost` | 서리 결계 |
| `sk_heal` | 치유의 빛 |
| `sk_shield` | 비전 방벽 |
| `sk_bolt` | 사슬 번개 |
| `sk_blink` | 차원 도약 |
| `sk_summon` | 영혼 늑대 소환 |
| `sk_deny` | 못 쓰는 스킬을 눌렀을 때 |

## E-2. 프롬프트

전부 **건조하게, 잔향 없이, 음악 없이**. 스킬음은 전투 한복판에서 울리므로
꼬리가 길면 다음 소리를 먹는다. 길이는 적어 둔 것을 지킬 것.

**sk_slash** — 0.25초
```
A wide heavy blade sweeping through the air in one fast arc. Low whoosh with a
metallic edge at the end, like a greatsword cutting a half circle. Dry, close,
no reverb, no music, no impact thud.
```

**sk_whirl** — 0.18초, 0.28초마다 반복해서 울린다
```
One revolution of a spinning blade passing the listener. Short airy whoosh,
lighter than a full swing, no attack transient. It will be repeated several
times in a row, so it must loop cleanly without a distinct start. Dry, no
reverb, no music.
```

**sk_charge** — 0.3초
```
A heavy body lunging forward and slamming into something. A short rush of air
followed immediately by a blunt armored impact. Low and forceful, no ring, no

```

**sk_quake** — 0.5초
```
Stone ground splitting open. Deep low crack with rubble and grit tearing away
from it, spreading outward. Weighty and dry, felt more than heard, no musical

```

**sk_guard** — 0.3초

```
Heavy armor plates locking into a braced stance. Metallic clamp that settles
into a solid low thunk, confident rather than harsh. Dry, close, no reverb,
no music.
```

**sk_shout** — 0.45초
```
A war shout that turns into a pressure wave. A short human roar, low and
throaty, immediately swallowed by a blast of air pushing outward. Not a word,
not a scream of pain. Dry, close, minimal reverb, no music.
```

**sk_volley** — 0.3초
```
Several arrows released from a bow at once. A tight cluster of bowstring
releases and shafts cutting air, overlapping within a fraction of a second.
Dry, close, no reverb, no music, no impact.
```

**sk_pierce** — 0.25초
```
A single arrow released with enormous force. A sharp snap followed by a thin
high whistle receding fast, as if it never stops. Dry, close, no reverb,
no music.
```

**sk_smoke** — 0.5초
```
A smoke bomb bursting and billowing outward. A soft pop followed by a broad
airy hiss that spreads and thins. Muffled and diffuse, no sharp transient,
no reverb, no music.
```

**sk_mark** — 0.25초
```
A hunter's mark snapping onto a target. Two short rising tones like a scope

Dry, no reverb, no music.
```

**sk_fire** — 0.35초
```
Fire catching and rushing forward. A low ignition thump that blooms into a
rising airy roar, like a fireball leaving the hand. Dry, close, no reverb,

```

**sk_meteor** — 0.8초
```
A burning mass slamming into the ground. Enormous low impact with a deep
```

**sk_frost** — 0.4초

```
Frost spreading outward and cracking. A high crystalline shatter over a low

```

**sk_heal** — 0.45초

```
A warm restorative glow settling over a body. A soft rising chime with a gentle
```

```
Electricity arcing from one target to the next. A sharp crackling snap with a
```

**sk_blink** — 0.25초

```
A spirit beast called out of nothing. A low breathy howl forming out of air,
```

```
A button press that refuses. One short dull muted click, low and soft, with no
```

## E-3. 파일이 없어도 소리는 갈린다

재질음과 같은 장치다. `game/js/game.js` 의 `sfx()` 안에 갈래마다 다른
합성음 규격이 들어 있어서 — 시작·끝 주파수, 파형, 크기, 잡음 섞는 정도 —
**파일을 한 개도 안 넣은 지금도 열다섯 갈래가 서로 다르게 들린다.**
파일은 급한 것부터 하나씩 넣으면 된다.

## E-4. 소리 말고 같이 들어간 것

소리만으로는 손맛이 안 산다. 같은 표(`SKILL_FX`)가 셋을 더 들고 있다.

| | |
|---|---|
| `k` | 화면 흔들림. 세기 순서대로 0 · 4 · 7 · 10 · 14 · 20 으로 다시 매겼다 (예전에는 다섯 스킬에만 손으로 적혀 있었고 열넷은 0이었다) |
| `st` | **손이 멈추는 한 박자.** 큰 것이 닿는 순간 세계가 0.03~0.10초 선다. 격투 게임의 히트스톱이고, 이 게임에는 아예 없었다 |
| `c` `r` | 시전 고리의 색과 크기. 화살 세례·비·화염구·늑대·표식처럼 **제자리에 아무 표시도 안 남던** 스킬에 특히 크다 |
