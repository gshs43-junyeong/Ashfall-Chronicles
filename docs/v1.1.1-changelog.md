## 1. 놀이

- **밭 물.** 작물은 젖은 밭에서만 아침에 자란다. 물을 주면 사흘 동안 젖고, 5칸 안에 물이 있거나 비가 오면(하늘이 트인 밭) 저절로 젖는다.
  - **물뿌리개**(20번) — 물 칸 우클릭으로 채우고 밭 · 작물 우클릭으로 준다.
  - **양동이** — 물 칸을 통째로 떠 온다. 물 양동이는 빈 칸에 부으면 물 한 칸.
  - **스프링클러**(기계) — 물 양동이를 받아 아침마다 좌우 25 · 위아래 6칸의 밭을 적시고 빈 양동이를 내놓는다. 전력 3.
- **드래곤.** 윤슬이 불 · 흙 · 전기 · 암흑 알을 판다. 깨면 1레벨 새끼 → 어린 용(10) → 성룡(20) → 고룡(30). 10 · 20 · 30 레벨에서는
  경험치가 찬 채 멈추고, 하늘 섬 재료(폭풍 호박 · 구름 진주)와 운석 · 별빛 수정으로 만든 먹이를 먹어야 넘는다. 최소 레벨 62.
- **레벨 곡선.** 장 보상만으로 세션 2 를 40, 세션 3 을 60 레벨에 맞이하고 마지막 장에서 75. 몹 한 마리는 그 구역 레벨 필요 경험치의 4% 남짓,
  보스는 1.5레벨 남짓. 비문 · 사당 · 맥박 사건 · 메아리의 경험치는 지금 레벨의 몇 할로 준다. 펫 능력치 · 최소 레벨도 이 기준으로.
- **탐지기 켜기.** 유틸리티 칸의 금속 · 몬스터 탐지기를 <kbd>Z</kbd> · <kbd>X</kbd> 로 켜면 파동이 퍼져 그 순간 보이는 것을 드러낸다.
- **광상.** 큰 광맥 덩어리 한가운데에 드릴로는 줄지 않고 곡괭이로는 한 등급 더 나오는 광상이 박힌다.
- 버프마다 HUD 아이콘 · 브라우저 확인 창 대신 게임 안 확인 창 · 가끔 이름을 불러 주는 마을 사람들.

## 2. 언어와 기기

- **다국어.** 설정 → 언어, 또는 주소 `?lang=en`. 처음에는 브라우저 언어를 따른다. 언어마다 글꼴을 고르고, 여섯 언어 모두 화면 넘침 검사를 통과했다.
  사이트(홈 · 내려받기)도 같은 언어 선택을 쓴다.
- **터치.** 손가락이 주 포인터인 기기에서 가상 스틱 · 점프/대시 · 탭 · '사용' 전환 · 스킬 칸 탭 · 전체 화면이 켜진다(`?touch=1` · `?touch=0` 으로 강제).
  폰 세로에서는 가로로 돌리라는 안내, 노치 기기는 안전 영역을 비운다. UI 크기 설정.
- **화질.** 자동 = 폰 절약 · 태블릿 보통 · 컴퓨터 높음(픽셀 밀도와 입자 상한).

## 3. 그림 · 소리 · 사이트

- 새 타이틀 로고 · 파비콘 · 16:9 대표 그림.
- 주인공 시트: 뒤로 흔든 팔이 몸에 붙고, 망토가 어깨에서 발목까지 흐르며, 피격 · 대시 장의 발끝이 뭉툭해졌다. 가슴 끈은 흔들리지 않는다.
- 스프링클러 · 물뿌리개의 물은 점이 아니라 가는 물줄기 — 스프링클러 줄기는 적시는 범위까지 닿는다.
- 해는 노을빛을 두르고, 깊은 골짜기에서도 하늘이 보이며, 비 오는 날에는 해가 옅어진다.
- 사이트: 마을 사람들이 시스템을 하나씩 소개하는 홈, 핵심 시스템 스크린샷(영어 화면), 여섯 언어.

## 4. 고침

- 죽은 뒤 일시정지가 풀리지 않던 것 · 잠긴 칸이 입력 초점을 빼앗던 것 · 가만히 떠 있을 때 나던 헤엄 소리.
- 언어를 바꾸면 장비 접사가 옛 언어로 남던 것(접사를 표 번호로 저장 — 세이브 v11).
- 장식 물건의 그림 칸 · 장착 알림 · 부서지는 흙먼지 · 몇몇 물건값 · 어색한 문구.

## 5. 만드는 쪽

- 코드 원본이 `src/`(TypeScript)로 — 게임 `src/game`(ES 모듈 · 파일당 1,200줄 이하 · 느슨한 타입) · 게임을 모르는 엔진 `src/engine`(strict).
  esbuild 가 `game/js/ashfall.js` 하나로 묶고, 번들은 커밋한다(`game/` 만 받아도 빌드 없이 돈다). `npm run dev` 로 고치고 새로고침.
- 엔진: core · save · audio · assets · platform · input · tilemap · render · i18n · entity · scene · ui — `docs/engine.md`, 예제 `games/sample`.
- `npm run check` — 문법 · 모듈 경계 · 세계 생성 해시 · 동작 스크립트 · 스크린샷 대조를 한 번에, CI 에서도.
- Docker — `docker compose up dev|game|site` · `docker compose run --rm check`.
- `tools/README.md` — 도구 목록. 게임 폴더에 섞여 있던 쓰지 않는 원본(보스 원본 그림 · 옛 굽기 스크립트)을 치웠다.
