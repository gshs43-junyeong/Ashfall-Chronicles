# 별이 잠든 땅 — Ashfall Chronicles (Windows)

## 세 줄이면 끝납니다

1. zip 을 풀어 주세요. (폴더째 풀어야 합니다 — 안의 파일만 꺼내면 안 됩니다)
2. 폴더 안의 **`AshfallChronicles.bat`** 또는 **`index.html`** 을 더블클릭하세요.
3. 브라우저가 열리면 바로 시작합니다.

설치할 것은 없습니다. 서버도, 파이썬도 필요하지 않습니다.

---

## 알아 두면 좋은 것

**시크릿 창(InPrivate)에서는 하지 마세요.** 저장이 그 창을 닫는 순간 사라집니다.

**저장은 브라우저 안에 남습니다.** 폴더를 옮기거나 다른 브라우저로 바꾸면 이전
기록이 안 보일 수 있습니다. 옮기기 전에 게임 안 **설정 → 저장 내보내기**로 JSON
파일을 받아 두고, 옮긴 뒤 **가져오기**로 되돌리면 됩니다.

**웹에서도 같은 게임을 할 수 있습니다** — <https://ashfall-chronicles.vercel.app/play>.
zip 은 같은 파일의 오프라인 복사본입니다.

---

## 잘 안 될 때

| 이럴 때 | 이렇게 |
|---|---|
| 그림이 안 보이고 검은 화면만 | zip 을 폴더째 풀었는지 확인하세요. `assets` 폴더가 `index.html` 과 같은 자리에 있어야 합니다 |
| bat 을 눌러도 아무 일이 없다 | `index.html` 을 직접 더블클릭해 보세요. 결과는 같습니다 |
| 저장한 기록이 사라졌다 | 시크릿 창이었거나 폴더를 옮긴 경우입니다. 설정의 내보내기/가져오기를 써 주세요 |
| SmartScreen 경고 | bat 은 브라우저를 여는 두 줄짜리 파일입니다. "추가 정보 → 실행"으로 넘어가거나, 그냥 `index.html` 을 여세요 |
