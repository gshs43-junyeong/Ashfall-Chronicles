# 별이 잠든 땅 — Ashfall Chronicles

테라리아식 2D 샌드박스 위에 스토리·RPG 성장·무기/능력 빌드를 얹은 어드벤처 게임입니다.
v1.0.5

---

## v1.0.5 변경 사항

### 새로운 요소

- **플레이어 이름 지정 + 저장 슬롯 3개** — 타이틀 화면이 슬롯 목록으로 바뀌었습니다.
  슬롯마다 이름·레벨·마지막 저장 시각이 따로 표시되고, 슬롯별로 다른 캐릭터를 키울 수
  있습니다. (이전 버전의 저장 기록은 첫 실행 때 1번 슬롯으로 자동 이전됩니다.)
- **여명 마을 금고에 금화 보관** — 보관고에서 금화를 넣고 뺄 수 있습니다. 죽어도 금고에
  넣어 둔 금화는 잃지 않습니다.
- **울림 정글 폭포 호수에 수련잎과 물고기** — 수면에 뜬 수련잎은 밟고 건널 수 있는
  발판입니다. 호수에는 비단잉어가 헤엄쳐 다닙니다.
- **타이틀 화면에서도 설정을 열 수 있습니다.** 조작법과 설정 창의 모양을 통일했습니다.

### 고친 것

- **작업대·용광로 그림이 안 나오던 문제** — 레벨별 그림(Lv.1~3)이 실제로 반영됩니다.
  책장 그림도 새로 들어갔습니다.
- **NPC·작은 동물(들토끼·눈산토끼 등)이 공중에 떠 보이던 문제** — 그림마다 다른 여백을
  실제로 재서 발끝을 땅에 맞춥니다.
- **얼음 지형에서는 비 대신 눈이 내립니다.** 베이스캠프에서도 비가 보입니다.
- **퀘스트 화살표와 거리 글자가 겹치던 문제.**
- **장비 창의 빈 펫 칸 아이콘이 왼쪽으로 치우쳐 있던 문제.**
- **유적 장식 보강** — 얼음 던전 지상 탑 내부가 텅 비어 있던 것을 비롯해, 유적 방마다
  깃발과 횃불을 더 놓았습니다.
- **여명 마을 3단계 손질** — 성문 안쪽이 하늘로 뚫려 보이던 것, 성벽을 뚫고 자란 나무,
  성문 앞을 막던 모래주머니, 2층 바닥 줄 양옆에 뚫려 있던 구멍, 공중에 떠 있던 전주를
  모두 고쳤습니다. 전주 기둥과 성벽 배경은 통행·경작을 막지 않습니다.
- **폭주로(7장) 방 배치 겹침 수정.**

## v1.0.4 변경 사항

- **여명 마을 좌표 배치 전면 재설계** — 분수대·NPC·시설·게시판·건물이 서로 겹치지 않도록
  배치표(좌표 슬롯)로 관리하고, 배치 뒤 자동으로 겹침 여부를 검사합니다. 앞으로 마을이
  확장돼도 같은 방식으로 겹침 없이 늘어납니다.
- **분수대 재제작** — 실제 그림에 맞는 물받이·좌우 대칭으로 다시 놓았고, 상호작용하면
  금화를 던지고 소원을 빌 수 있습니다(버프 획득).
- **성문 신규 제작** — 3단계 성벽의 정문이 집 문을 억지로 늘린 모습이 아니라 성문 전용
  그림으로 바뀌었습니다.
- **여관 침대 재제작** — 바닥에 붙지 않고 작아 보이던 문제를 고치고, 크기를 키워 다시
  배치했습니다.
- **작업대 · 용광로 · 책장을 2칸 크기로 확대**, 레벨(1~3)마다 다른 그림이 나옵니다.
  설치할 때 여러 칸을 차지하는 시설끼리 겹치지 않도록 충돌 판정도 함께 강화했습니다.
  베이스캠프·마을·직접 설치한 시설의 크기가 이제 전부 하나의 기준을 씁니다.
- **제작(`H`) 탭이 실제로 가까이 있는 시설만 보여주도록 수정** — 예전엔 시설에서 멀리
  떨어져도 마지막으로 들렀던 시설 탭이 계속 남아 있었습니다.
- **여명 마을 2층 집에 오르내리는 발판을 새로 놓았습니다** — 전에는 2층에 지붕과 창문만
  있고 오를 방법이 없었습니다. 2층에는 책장도 하나씩 놓았습니다.
- **버섯 골짜기 캐노피를 타일 텍스처로 교체** — 나뭇잎이 낱개 버섯이 뭉쳐 보이던 문제를
  고쳤습니다.
- **비정상적으로 높이 자라는 나무 버그 수정.**
- **나무통이 바닥에 붙지 않던 문제 수정.**
- **마을에서 비가 올 때도 빗줄기·하늘 연출이 나오도록 수정**(마을 배경음악은 그대로
  유지됩니다).
- **폭주로(7장) 안쪽 방 배치 겹침 수정** — 아주 드물게(약 300분의 1) 증식체의 노심과
  헤파의 격실이 같은 방에 겹쳐 놓이던 경우를 없앴습니다.

## 실행 방법 (Windows)

압축을 푼 폴더 안의 **`AshfallChronicles.bat`** 을 더블클릭하세요. 검은 명령 창이 뜨고,
잠시 뒤 기본 브라우저로 게임이 열립니다.

- **Python 3 이 필요합니다.** 없으면 안내 문구가 뜹니다.
  [python.org/downloads](https://www.python.org/downloads/) 에서 설치하고, 설치 화면의
  **"Add python.exe to PATH"** 를 반드시 체크하세요.
- 처음 실행할 때 Windows Defender/SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
  로컬 서버만 띄우는 배치 파일이라 인터넷으로 나가지 않습니다.
- 게임을 끝내려면 그 명령 창을 닫으면 됩니다(서버도 같이 꺼집니다).

## 실행 방법 (macOS)

압축을 푼 폴더 안에서 아래 둘 중 하나를 쓰면 됩니다. 둘 다 브라우저 창 하나가 뜨면서
게임이 시작됩니다.

### 1) 더블클릭 (macOS, 가장 쉬움)

`AshfallChronicles.command` 파일을 더블클릭하세요. 터미널 창이 자동으로 뜨고,
잠시 뒤 브라우저로 게임이 열립니다.

**처음 실행할 때 "확인되지 않은 개발자" 경고가 뜰 수 있습니다.** 이건 앱을 지우거나
막는 경고가 아니라 그냥 확인창입니다 — 파일을 **우클릭 → 열기**를 누르면 그 뒤로는
경고 없이 바로 실행됩니다. (더블클릭으로 뜨는 경고에서 "취소"를 누른 뒤 다시
우클릭 → 열기를 시도해도 됩니다.)

게임을 끝내려면 자동으로 뜬 터미널 창을 닫으면 됩니다.

### 2) 터미널에서 직접

```bash
cd 압축을_푼_폴더_경로
bash launch.sh
```

두 방법 모두 로컬 웹 서버를 하나 띄우고 그 주소로 브라우저를 여는 방식입니다.
인터넷 연결이 필요 없고, 이 폴더 밖 어디에도 파일을 설치하지 않습니다.

## 시스템 요구사항

- macOS (Python 3이 기본 내장된 버전이면 별도 설치 없이 바로 됩니다)
- Windows 10 이상 + Python 3 (설치 시 "Add python.exe to PATH" 체크)
- 최신 브라우저(Chrome·Safari·Edge 등) — 게임은 그 브라우저 창 안에서 돌아갑니다
- 특별한 사양 요구 없음. 저사양 노트북에서도 무난히 돌아갑니다

## 주의사항

- **폴더째로 옮기거나 압축해서 전달해도 됩니다.** `AshfallChronicles.command`/`launch.sh`가
  자기 위치를 기준으로 동작하므로, 어디에 풀어놔도 상관없습니다.
- **저장 데이터는 이 게임을 튼 브라우저 안에 저장됩니다**(`localStorage`). 그래서:
  - 같은 브라우저로 다시 실행하면 이어하기가 됩니다.
  - 브라우저를 바꾸거나(Chrome→Safari 등), 브라우저의 "방문 기록·사이트 데이터 삭제"를
    누르면 저장이 사라집니다. 저장을 지키고 싶다면 항상 같은 브라우저로 실행하세요.
  - 시크릿/프라이빗 모드로 열면 창을 닫는 순간 저장이 날아갑니다.
- 실행 중 뜬 터미널 창은 게임의 로컬 서버입니다. **닫으면 게임도 같이 꺼집니다.**
- 브라우저 탭만 닫고 터미널 창은 살아있다면, 같은 주소(`http://127.0.0.1:포트번호`)로
  다시 들어가면 이어집니다. 주소는 터미널 창에 적혀 있습니다.

## 문제가 있을 때

| 증상 | 확인할 것 |
|---|---|
| 더블클릭해도 아무 반응이 없다 | 우클릭 → 열기로 다시 시도. 그래도 안 되면 터미널에서 `bash launch.sh` 실행 |
| 화면이 하얗거나 그림이 안 뜬다 | 브라우저에서 새로고침(⌘R). 그래도 안 되면 터미널 창을 닫고 다시 실행 |
| 소리가 안 난다 | 브라우저 창을 한 번 클릭하거나 키를 눌러 보세요 — 브라우저 정책상 첫 사용자 입력 전에는 소리가 자동으로 나오지 않습니다 |
| "포트가 이미 사용 중"이라고 뜬다 | 이미 게임이 다른 터미널 창에서 켜져 있는 상태입니다. 그 창을 찾아 이어서 쓰거나 닫고 다시 켜세요 |

## 조작

| 입력 | 동작 |
|---|---|
| `A` / `D` | 이동 |
| `Space` | 점프 (특성·장신구로 이중 점프) |
| `S` | 나무 발판 아래로 내려가기 |
| 좌클릭 | 장착 무기로 공격 — 핫바에 곡괭이/괭이를 든 상태면 채굴/밭갈이 |
| 우클릭 | 블록/기계 설치 · NPC/상자/제단/기계 상호작용 · 낚싯대는 물에 던지기 |
| `Shift` | 회피 대시 (무적 프레임) |
| `Q` `E` `R` `F` | 스킬 슬롯 |
| `1`~`9`, `0` | 핫바 · 마우스 휠로도 전환 |
| `I` `K` `J` `H` | 가방 · 능력 · 일지 · 제작 |
| `Esc` | 일시정지(설정 창 포함) |
| `F5` | 저장 |
| `Shift`+좌클릭 (가방 안) | 해당 칸 즉시 버리기 |
