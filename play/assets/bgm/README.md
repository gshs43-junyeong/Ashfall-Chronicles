# 배경음악 넣는 곳

이 폴더에 곡 파일을 **상황 키 이름**으로 넣고 `node tools/sync-bgm.mjs` 를 한 번 돌린 뒤 커밋하면 게임이 그 곡을 튼다.
목록(`../bgm-manifest.js`)은 도구가 쓴다 — 손으로 고치지 않는다. 비어 있는 키는 아래 '대신 트는 곡'으로 내려가므로
몇 곡만 있어도 된다(전부 비면 음악 없이 돈다).

| 파일 이름 | 언제 흐르나 | 없으면 대신 |
|---|---|---|
| `title` | 타이틀 화면 | normal |
| `normal` | 평상시 지상(낮) | — |
| `tense` | 밤 · 어두운 굴 · 체력 30% 아래 · 비 말고 날씨(붉은 달 · 모래 폭풍 · 포자) | normal |
| `rain` | 비 · 눈 | tense |
| `boss` | 보스 결전 | tense |
| `village` | 여명 마을(세션 2부터 — 세션 1 은 `lastnote`) | normal |
| `east` | 버섯 골짜기 · 부패한 땅 | normal |
| `catacomb` | 유적 · 던전 · 심층 | tense |
| `sky` | 하늘 섬 · 부유 성채 | normal |
| `sea` | 바다 수면 · 해변 · 빙하 지대 | normal |
| `seadeep` | 물속 | sea |
| `lastnote` | 쓰러진 화면 · 무너진 마을(세션 1) | tense |
| `finale` | 세션의 마지막 결전 | boss |

- **확장자**: `.m4a`(AAC 160k 권장) · `.mp3` · `.ogg` · `.opus` · `.wav`(크다 — 도구가 경고). 12MB 를 넘으면 경고.
- **같은 키에 여러 곡**: `normal_1.mp3` · `normal_2.mp3` … — 틀 때마다 그중 하나를 고른다.
- **반복**: 곡은 끝나면 처음으로 돌아간다(이음매 없이 돌게 만들면 좋다). 바뀔 때는 0.9초 교차 페이드.
- **소리 크기**: 곡끼리 비슷하게(대략 -14 LUFS). 게임이 볼륨 0.42 를 곱한다.
- **이름을 틀리면** 도구가 멈추고 쓸 수 있는 이름을 알려 준다. 같은 이름으로 곡을 바꿔도 된다(주소에 내용 해시가 붙어 웹 캐시가 새로 받는다).
- 새 상황을 만들려면 `src/game/music.ts` 의 `BGM_KEYS` · `BGM_FALLBACK` 과 `src/game/game.ts` 의 `pickBgm` 을 고친다.
